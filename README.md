# PENTAX LABS — Public Edition

**在线网页版：** https://linda6177.github.io/PENTAX-LABS-WEB/

**最新版桌面端：** https://github.com/linda6177/PENTAX-LABS-WEB/releases/latest/download/PentaxLabs_Lite_Latest.tar.xz

**版本发布页：** https://github.com/linda6177/PENTAX-LABS-WEB/releases/latest

Pentax Labs 是面向 PENTAX / RICOH 相机用户与影像研究者的独立工具集，提供桌面端和浏览器端两种使用方式。它将自定义滤镜制作、相机脚本导出、原厂色彩参数预览、工程模式资料、四季滤镜启用工具和 *ist D 专用工具集中在一个工作流中。

> 本项目为个人独立开发的非官方软件，与 RICOH IMAGING / PENTAX 无隶属、授权、赞助或认可关系。相机型号名称仅用于说明兼容范围。

## 核心功能

### 1. 自定义滤镜工作室

- 浏览原厂滤镜库，将原厂风格作为起点继续调整。
- 编辑 3×3 色彩矩阵、亮度及 R/G/B 通道曲线；曲线采用平滑意图模型，支持点击曲线添加控制点、拖动局部调整、Alt 拖动整体塑形、右键删除节点。
- 使用照片或内置色卡进行预览，支持原图对比、缩放和平移。
- 保存用户滤镜、重命名、排序、批量选择、删除及 LUT 导入导出。
- 支持 `.cube` LUT 拟合；可查看拟合结果并将可表达的部分转换为相机原生参数。
- 提供三个相机滤镜槽位的编辑与导出工作流。槽位在机身上的显示、切换和保存行为取决于相机型号及固件。

**重要的成像边界：** 相机原生矩阵与 Gamma 并不等价于完整 3D LUT。复杂 LUT、局部色相变换和多维色彩操作无法保证无损还原。软件预览、拟合评分与相机最终 JPEG 是不同的验证层级；请以目标机身实拍为最终判断，不要把软件预览误认为已完成所有机型的所见即所得标定。

**K-1 II LUT 算法：** Beta86 起，K-1 II 的 `.cube` 导入使用 R369 原生 Matrix/Gamma 模型和 12k Natural 相机校准样本；K-1 与 *ist D 继续使用各自的 P317 路线。Web 端采用 JavaScript 分块优化器，桌面端采用 SciPy 优化器，共享校准数据、原生矩阵基底和暗部加权目标。当前 NEG/POSI 交叉样本的 Q8 矩阵逐项一致，Gamma 量化值存在小幅数值差异；软件拟合分数不代表机内 JPEG 实测色差。

**Beta87 Web：** K-1 脚本导出改为与桌面 Beta73+ 相同的 R30 快速启动（6,078 B），不再发布旧的 17,993 B R29 安装脚本。导出同时替换三个自定义槽位图标，避免未启用槽位残留原厂 POSI/NEGA 图标。此变更只影响 K-1 脚本容器，不改变 K-1 的 P/R 二进制、色彩参数或 K-1 II 的 R367/R369 路线。

### 2. 自定义滤镜脚本与机型支持

当前公开版自定义滤镜脚本导出器提供以下机型配置：

| 机型 | 导出能力 / 说明 |
|---|---|
| PENTAX *ist D | 专用 3×3 Matrix + 共享 4096 点 Gamma；不具备 K 系列三路独立 RGB Gamma 的表达能力，复杂 LUT 拟合范围较受限 |
| PENTAX K-1 | 独立 R29 三槽运行底座；图标、切换、拍摄及重启已有实机验证。原机新槽的 Info 参数不支持独立保存。脚本启动器使用与桌面一致的 R30 快速版（6,078 B）。 |
| PENTAX K-1 II | P286 架构的 R367 稳定运行底座；LUT 导入使用 R369 原生 Matrix/Gamma 拟合；与 K-1 不共用运行时文件 |

项目内部称 K12 的设备对应 K-1 II 平台研究线；界面和公开兼容表使用官方型号名称 **K-1 II**。K-1 与 K-1 II 的脚本底座不可混用。每次新生成的参数组合仍应在目标机身上验证；当前发布包不代表所有组合都已实机认证。

### 3. 正负逆冲（Cross Processing）

- 使用原厂矩阵银行与 Random / Extended 生成模式。
- 调整饱和度、色相、影调、对比度、锐度等机内参数。
- 查看 R/G/B 三路原厂 ROM 曲线，并分别选择曲线编号。
- 导出机内 10B 配方，或导出当前预览 PNG。
- 矩阵数值编辑面板已移除；矩阵作为原厂内部基底参与成像，不提供自由矩阵编辑。

### 4. 工程模式（Service / Factory）

工程模式页按相机型号提供对应的入口类型、文件和操作说明。资料库覆盖多代机型，包括 *ist 系列、K100D/K110D、K10D/K20D、K-5 系列、K-30/K-50、K-3/K-3 II、K-1/K-1 II、K-70、KP、K-3 III、KF 等。**资料库出现某机型不等于所有固件版本均已实机验证**：每个条目会区分按键教程、公开文件重建、固件元数据核验、原始函数离线验证和实机确认等证据状态。

典型流程：选择准确机型和固件对应的入口 → 选择 SD 卡根目录或测试目录 → 导出入口文件 → 安全弹出 SD 卡 → 按该机型教程进入菜单。不要混用不同型号的入口文件；K-3 III 的 Service Menu 与 Factory Menu 是不同入口，脚本开关位于 Factory 菜单路径。

### 5. 四季滤镜启用脚本

四季脚本适配范围为 **K-1、K-1 II、K-3 III 彩色版、KF**。K-3 III Monochrome 不在适配范围内。机型对应的工程入口、命令名称和启动方式不同，必须在界面中选择准确型号。

- 可单独选择春、夏、秋、冬，也可全选；另有探测、撤销等辅助操作。
- 常规工作流为：准备工程入口 → 在机身启用 Script Mode → 运行脚本探测 → 导出并执行所选季节命令 → 在相机菜单确认并拍摄验证。
- K-1 II / K12 的四季启用已有用户实机成功记录；其他适配机型的部分入口或持久化行为仍需按指南标注的状态进行实机核验。
- K-1 / K-1 II / KF 与 K-3 III 使用的季节命令后缀并不完全相同，程序会按型号生成，不要手工复制其他机型的脚本。

**注意：** 写卡成功只证明文件写入成功，不等于机身已经启用。某些机型需要保留启动脚本才能维持强制启用状态。请按对应机型指南检查相机菜单和 RAW+JPEG 实拍结果。

### 6. *ist D 工具箱

- 导出 *ist D Firmware 1.12 中文固件文件（固定文件名 `FWDC112B.BIN`）。固件升级由相机自身执行，软件不会自动刷写。
- 生成 AF Fine Adjustment 调焦文件，范围 −64 至 +64，默认值 +32。
- *ist D 自定义滤镜使用该机身可表达的共享 Gamma 与矩阵模型，不应套用 K-1 / K-1 II 的三路 Gamma 能力描述。

### 7. 多语言与外观

Web 与桌面端提供同源多语言界面。当前语言选项包括：系统自动、简体中文、繁体中文、English、日本語、Español、Français、Deutsch、Italiano、Português、한국어、Русский、Tiếng Việt。系统自动模式会根据浏览器或系统语言选择界面语言；用户也可以在设置中手动切换。桌面端与网页端均提供主题强调色设置（具体选项随版本界面为准）。

## 快速使用说明

### Web 公共版

1. 打开 https://linda6177.github.io/PENTAX-LABS-WEB/ 。建议使用最新版 Edge 或 Chrome。
2. 在设置中选择界面语言；进入自定义滤镜页，选择预览照片或使用内置色卡。
3. 选择原厂滤镜或用户滤镜作为起点，调整矩阵和曲线。曲线可单击加点并拖动；Alt + 拖动调整曲线整体，右键删除中间点。
4. 保存用户滤镜；需要导出相机脚本时，在相机型号选择器中选定 *ist D、K-1 或 K-1 II，再执行导出。
5. 首次写入 SD 卡时，浏览器会要求用户通过系统目录选择器授权目标目录。选择 SD 卡根目录，不要选择 `script` 子目录。浏览器的目录写入能力受浏览器和权限限制；不支持 File System Access API 时会回退为下载文件。
6. 工程模式、四季滤镜和 *ist D 工具箱按各页面的机型说明选择文件并导出。写卡后安全弹出，再按对应相机指南操作。

### Windows 桌面版

1. 从 GitHub 最新 Release 下载桌面包： https://github.com/linda6177/PENTAX-LABS-WEB/releases/latest 。
2. 解压完整目录后运行 `PentaxLabs_betaXX_Lite.exe`。不要只复制 EXE 单文件，也不要删除 `_internal` 运行资源目录。
3. 进入自定义滤镜页，选择目标机型、滤镜槽和预览照片，完成调整后保存或导出。
4. 导出脚本、工程入口或四季启用文件时，选择 SD 卡根目录或空白测试目录；确认型号和卡盘符后再写入。
5. 安全弹出 SD 卡，装入相机，按对应型号和固件版本的说明执行。写入操作不代替机身端验证。

## SD 卡写入与安全须知

- 优先使用空白测试卡或先完整备份 SD 卡。写入前核对盘符、卡槽、机型和固件版本。
- 选择 SD 卡根目录，不要把 `script` 子目录本身当作目标根目录。
- 程序对已知冲突文件会按工具规则备份或校验；不要手动删除不认识的触发文件或启动脚本。
- 工程模式和四季脚本不会自动刷写相机固件，也不会自动执行相机菜单中的校准、初始化或数据导入操作。
- 不要在不理解用途时进入并修改校准、EEPROM、镜头 ROM、Initialize 或 Adjust Data 项目。
- *ist D 固件升级有风险，务必确认机型、电池电量、文件完整性，并遵循相机自身升级流程。
- 四季脚本的执行标记只说明脚本运行到相应位置，不单独证明滤镜已在机身成功启用；必须检查菜单并实拍确认。

## 已知限制

- Web 端依赖现代浏览器能力；目录直写需用户明确授权，网页无法静默访问电脑磁盘或自动识别 SD 卡。
- 复杂 3D LUT 无法保证转换成机内矩阵与曲线后完全一致。
- 不同相机平台、固件版本和槽位实现存在差异；不要跨机型混用脚本运行时资源。
- 工程模式资料库包含不同证据等级，具体条目的验证状态以软件内说明为准。
- 本项目不承诺所有功能对所有机型、固件和地区版本均可用。
